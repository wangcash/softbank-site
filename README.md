# 开源软库

中国免费与开源软件索引，线上地址：<https://softbank.org.cn>

个人维护的非营利索引站，按领域整理中国开发者、企业和研究机构的优秀免费软件与开源项目，重点推荐 AI 软件，并收录开放原子开源基金会旗下的全部项目。

本站与软银集团（SoftBank Group Corp.）及其关联公司无任何关联，也不是开放原子开源基金会的官方网站。

## 目录结构

```
index.html   网站页面（样式、数据和脚本都在这一个文件里）
icons/       各项目图标，80×80 WebP
logo/        站点 logo（横版、图形、App 图标、深色版）
deploy.sh    自建服务器（Ubuntu + Nginx）的一键部署脚本
```

## 修改收录内容

数据都在 `index.html` 的 `<script>` 里：

| 数组 | 内容 |
|---|---|
| `AI` / `AICATS` | AI 专区的条目与分类，第 7 个字段填推荐理由即可进入精选 |
| `P` / `GROUPS` | 软件目录的条目与领域 |
| `OA` / `STAGES` | 开放原子开源基金会项目与阶段 |
| `LOGOS` | 条目与图标文件的对应关系，键名格式为 `分区:名称`，如 `AI:Dify` |

新增图标时，把图片放进 `icons/`，再在 `LOGOS` 里加一行对应关系。没有配置图标的条目会自动显示字母头像。

## 部署

- **Cloudflare Pages**（当前使用）：在项目里点「创建部署」，上传包含 `index.html`、`icons/`、`logo/` 的 zip 包。
- **自建服务器**：把网站打包成 `softbank-site.tar.gz` 上传到服务器，运行 `bash deploy.sh`。
